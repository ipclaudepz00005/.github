<h3>先分清哪些是「贵」哪些是「多」</h3>
<p>贵是单价问题，多是数量问题。两者的处理方式不同：单价要谈，数量要核。多数人的第一反应是去谈价，实际上问题常出在数量口径。</p>
<h3>要一份带明细的账单样例</h3>
<p>下单前直接要一份别人家的账单样例（脱敏即可），看它怎么列项：有没有单独的带宽行、有没有超量行、有没有变更行。列项越细，后期争议越少。</p>

<h2>二、分支一：单位看错，条、端口、地址、段</h2>
<p>这是差额最大也最容易被忽视的一支。同一个「一百元」，可能是十条共享端口，也可能是一条独享地址。</p>
<h3>四个词的实际含义</h3>
<p>地址指一个可用的公网 IP；端口指代理入口，一个入口可能对应多个出口，也可能多个用户共用一个出口；并发指同时建立的连接数；段指一整块地址（如 /24）。报价单上写「50 个 IP」，要问清是五十个独立地址还是五十个端口。</p>
<h3>核查动作</h3>
<p>拿到凭据后逐条验证：用脚本遍历所有出口，把返回的地址去重，数量对不对一目了然。<code>curl --proxy http://... -s https://api.ipify.org</code> 循环跑一遍，把结果排序去重即可。</p>
<p><strong>共享端口的合理预期。</strong>共享端口便宜，但同一入口会排队，高峰期延迟上升。如果业务对延迟敏感，省下的钱会以等待时间的形式还回去。</p>

<h2>三、分支二：用量超限，流量、带宽、并发三个口子</h2>
<img src="/tp.png" alt="住宅IP账单超额的四个分支与计费口径核查路径">
<p>这一支最隐蔽，因为超限往往发生在月中，等到发现已经产生费用。</p>
<h3>流量：计费方向是关键</h3>
<p>按 GB 计费的套餐，要问清计的是上行、下行，还是双向相加。看视频、传大文件时下行流量远大于上行，二者相差数倍。有些套餐标称不限量，实际设了公平使用阈值，超阈值限速，这条要落到文字上。</p>
<h3>带宽：独享还是共享</h3>
<p>按 Mbps 计费的带宽，问清是独享还是共享、峰值是否保证。共享带宽在高峰期跑不满标称值，这是常态，不算违约，但要在预期之内。</p>
<h3>并发：超了是排队还是加钱</h3>
<p>有些套餐并发超限直接拒绝连接，有些按超出部分加收。前者影响体验，后者影响账单，问清是哪种，比问并发数本身更重要。</p>

<h2>四、分支三：变更收费，换址换区重装</h2>
<p>长期使用一定会遇到变更，这一支的费用往往在第二个月才显现。</p>
<h3>三类变更的常见收费方式</h3>
<p>换地址：有的每周期含一到两次免费，超出按次收；换城市或换国家：多数按新开计费，原线路不退；重装系统或重置配置：部分供应商收开机费。三类都要在下单前确认。</p>
<h3>把免费额度写进合同</h3>
<p>口头说「可以换」没有意义，要写「每周期含 N 次免费换址，超出每次 X 元」。这句话写进去，后续沟通成本会低很多。</p>
<p><strong>变更后的周期怎么算。</strong>换址后剩余周期是否延续、是否重新起算，直接影响实际单价。若每次换址都重置周期，实际成本可能比标价高两三成。</p>

<h2>五、分支四：周期、续费与阶梯价</h2>
<p>最后这一支不涉及用量，纯粹是时间口径问题，却最容易在财务对账时被发现。</p>
<h3>自然月还是三十天</h3>
<p>按自然月计费一年是十二个周期，按三十天计费一年是十二点二个周期，差额不大但会让续费日逐月漂移。团队报销时这种漂移很麻烦。</p>
<h3>自动续费要提前关</h3>
<p>多数平台默认开启自动续费，试用期结束会自动转正。若只是短期测试，到期前三天手动关闭，或使用一次性支付方式。</p>
<p><strong>阶梯价是按当期还是累计。</strong>有些报价表写「满五十条享折扣」，要问清是按当期数量算，还是按历史累计算。前者一旦减量就回到原价，预算要留出余量。</p>
<p><strong>对账留三样东西。</strong>报价单截图、合同条款页、每期账单明细。三样对齐，任何一笔异常都能在一个小时内定位到条款。</p>

<h2>常见问答</h2>
<h3>报价单上「不限流量」能信吗？</h3>
<p>答：可以信字面，但要问清阈值。多数不限量套餐设有公平使用条款，超过阈值后限速或降优先级。问清阈值数字和超限后的处理方式，比纠结这个词更有用。</p>
<h3>为什么第一个月便宜，第二个月就贵了？</h3>
<p>答：常见原因是首月按天折算、赠送额度用完后按原价、或试用期结束自动转正。核对首月账单的计费天数与赠送项，基本能解释差额。</p>
<h3>换地址收费合理吗？</h3>
<p>答：多数供应商会收，因为地址是稀缺资源。合理的做法是每周期给一定免费额度，超出再收费。完全免费且无限制的，通常意味着地址质量或复用率上另有安排。</p>
<h3>怎么在付款前验证计费口径？</h3>
<p>答：要求提供一份脱敏账单样例，并让对方在报价单上写明单位、计费方向、超量单价、免费变更额度四项。四项写清楚，后期争议会少很多。</p>
